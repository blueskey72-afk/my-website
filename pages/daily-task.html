📌 Task Rule

Teacher will create the task with a date, deadline and duration.

The student must complete the task before the deadline.

If the student completes the task on time, no consequence will be added.

If the deadline passes and the task is still incomplete, the teacher can decide whether a consequence should be added.

Custom consequences are managed separately from the Consequences page.
